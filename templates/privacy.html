Product information

Privacy

Soccer Scanner has no account system and does not sell personal information.

Data stored on this device

Score visibility is stored only for the current browser-tab session using sessionStorage. Scores start hidden in each new session. Dates, timezones, and filters are encoded in the current URL when you use them.

Soccer Scanner does not maintain a guest favorite profile or read legacy favorite data. Older browser data may remain until you clear this site's stored data in your browser.

Native iOS app

The native iOS app does not store a score-visibility preference between launches; scores start hidden each time. It has no account, analytics, crash reporting, or advertising SDKs, and it does not create a cross-device profile.

Each native API request includes a short-lived X-Request-ID so an operational failure can be traced. It is not used as an account identifier or for tracking.

Service operation

Short-lived request identifiers, rate-limit counters, and operational metrics help keep the service reliable. Provider keys and fixture scores are not written to application logs.

External services

Fixture and club information comes from the providers listed on the data sources page. League tables load an explicitly selected SofaScore embed.
