Product information

Data sources

Soccer Scanner combines available fixture coverage without inventing missing facts.

ESPN

ESPN provides the primary public fixture schedule and match-state coverage across tracked competitions.

Football-data.org

Football-data.org can add verified competition, club, team-analysis, and fixture fields when a server-side API key is configured.

SofaScore

The Tables page can load a SofaScore standings embed only after the user visits that workspace. Soccer Scanner does not merge those standings into fixture records.

Coverage policy

Unavailable values remain unavailable. Estimates are labeled, provider failures are shown separately from genuinely empty schedules, and each fixture retains source and freshness evidence.
