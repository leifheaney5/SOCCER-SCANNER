# Soccer Scanner marketing workspace

This workspace contains evidence-led messaging for the current product. Copy
must describe the experience without promising rights coverage, perfect data,
or real-time guarantees that the repository cannot prove.

## Approved product description

Soccer Scanner is a spoiler-safe fixture workspace for browsing soccer matches
across supported competitions, with local kickoff times, venue details, and
verified streaming information when a provider reports it.

## Safe claims

- Browse fixture schedules across the competitions currently returned by the
  configured providers.
- Keep scores hidden until the viewer chooses to reveal them.
- See streaming service, region, source, and official link details when they
  are verified.
- Share a fixture view without exposing hidden scores.
- Use the offline snapshot for settled fixtures previously loaded on the device.

## Claims that are not approved

Do not claim complete global coverage, guaranteed streaming availability,
perfect accuracy, official broadcaster partnerships, universal free access,
or guaranteed real-time updates. Broadcast rights vary by territory and the
absence of a listing means only that no verified listing was available.

## Evidence process

Every campaign claim must link to a current route, test, source registry entry,
or release-smoke result. Update this file when a capability changes; do not
silently broaden the copy based on provider assumptions.
